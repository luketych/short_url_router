# Dev Containers Configuration for URL Shortener Project

## Task
Create VSCode Dev Containers configuration files for the URL Shortener project.

## Files Created

1. `.devcontainer/devcontainer.json` - Main configuration file for the development container
2. `.devcontainer/docker-compose.yml` - Docker Compose configuration for the development environment
3. `.devcontainer/Dockerfile` - Custom Dockerfile for the development container
4. `.devcontainer/.env.example` - Example environment variables file for the development container
5. `.vscode/extensions.json` - Recommended VS Code extensions for the project
6. `.devcontainer/README.md` - Documentation for using the development container

## Implementation Details

### Intent
- Create a consistent, isolated development environment that matches production
- Simplify onboarding for new developers
- Include all necessary tools and dependencies
- Configure a local PostgreSQL database for development

### Changes Made
- Created a Node.js 20 development container with necessary development tools
- Added PostgreSQL database container with automatic schema initialization
- Configured volume mounts for code and node_modules
- Set up port forwarding for the application and database
- Added recommended VS Code extensions
- Created documentation for using the development container
- Configured environment variables for development

### Notes
- The development container uses a separate `.env` file to avoid conflicts with production
- The PostgreSQL database is configured with default credentials for development
- The container is set up to run in development mode with hot reloading
